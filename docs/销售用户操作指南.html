销售用户操作指南

每天只需要做两件事：把名单交给系统处理；处理系统筛出的“可发送”和“需确认”客户。不要手工逐条查邮箱，也不要对同一客户重复触发富化。

→标准闭环：获取线索 → 核验客户 → 邮件触达 → 跟进推进

每天怎么用

从左侧菜单依次完成，不需要跳步骤。

1. 获取线索上传 Excel/CSV，或精确找人
2. 核验客户看系统已处理的客户
3. 邮件触达确认邮件后发送
4. 跟进推进记录结果并更新阶段

1. 获取线索

适合你已有公司、联系人或展会名单的情况。

1

进入“获客线索” → “批量导入”

上传 Excel 或 CSV。优先保留：公司名称、官网、联系人姓名、职位、国家/地区、行业、邮箱、电话、LinkedIn 链接。已知邮箱和电话也可以直接导入。

2

填写默认地区和行业，点击“上传并开始获客”

系统会自动去重、补齐公司信息、生成客户画像和邮件草稿。导入完成不代表已经发信。

3

等待任务显示“等待核验”

点击“核验客户”进入下一步。不要反复上传同一文件；同一公司/联系人会自动合并或标记重复。

邮箱补齐说明：Hunter、Prospeo 等先处理；仍未找到邮箱的客户会自动进入 ContactOut 队列。队列按公司共享日额度执行，显示“次日队列”表示当天额度已经被更早任务占用，不是任务丢失。

2. 核验客户

系统先做大部分判断，销售只需要处理少数例外。

可发送已有有效邮箱。检查公司、联系人和邮件草稿，确认后进入邮件触达。
系统可自动补正在补公司/联系人/邮箱。先等任务完成，不要重复点击补齐。
需人工确认姓名、职位或邮箱候选可能不匹配。打开详情核对后再使用。
客户归属：你默认只看到自己的私有客户池；公共池客户需要领取后才进入你的池子。不要把他人私有客户重复导入。

3. 邮件触达

每封邮件先由系统结合公司、职位、国家和客户画像生成草稿，再由你确认。

1

进入“邮件中心”或客户详情

只处理“可发送”的客户。打开草稿，检查称呼、公司名称、核心合作理由和签名。

2

修改到像你本人会说的话

保留一条与对方业务直接相关的理由；删除系统内部字段、原始数据备注和不确定的描述。不要承诺未经确认的价格、回报或授权范围。

3

点击“发送”

系统会用当前登录销售绑定的发件身份发送，并记录主题、正文、发送时间和后续反馈。若客户已退订、退信或已回复，系统会停止自动触达。

4. 跟进推进

邮件发出后，重点不再是继续发，而是及时判断下一步。

已回复先阅读内容，记录沟通要点；将客户推进到“初步沟通/约会/商业计划”等阶段。
已打开未回复按系统建议准备第二次触达；换一个价值点，不要原文重发。
未打开或未反馈等待系统的下次触达建议。不要当天连续发送多封。
退信、退订或拒绝停止触达并补充原因。退订客户不可再次发送。
客户生命周期：线索 → 已回复 → 初步沟通 → 约会/会议 → 商业计划 → 试订单 → 代理协议 → 门店创建 → 签约维护。每次电话、WhatsApp、会议或报价，都在客户详情里记录一次。

销售每天只要记住这 5 件事

  1. 上传名单后，先让系统跑完；不要重复导入。
  2. 只在“可发送”和“需人工确认”里花时间。
  3. 发送前一定检查邮件第一段是否真的匹配客户。
  4. 客户一旦回复，当天记录结果并推进生命周期。
  5. 没有邮箱、退信、退订的客户，不要私下重复发送。
